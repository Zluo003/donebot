# Bitwarden 密码库

在设置的密码库页面连接个人 Bitwarden 或 Vaultwarden 账号。使用仅能访问所需项目的专用账号；该账号可见的登录信息和密钥对本工作区全部 Bot 可用，不提供按集合分配 Bot 的功能。

在 Bitwarden 账号设置的安全、密钥页面取得个人 API 的 `client_id` 和 `client_secret`，与主密码一起填写。支持 Bitwarden 美国、欧洲服务和 HTTPS 自建地址；自建服务可带路径，但不能包含地址凭据、查询或片段。

DoneBot 首次使用时下载固定版本 `2026.10.1` 的官方 OSS CLI，核对固定大小和 SHA-256，以独立子进程调用。CLI 和 SDK 均不作为 DoneBot 依赖或安装包内容。下载工具位于数据目录的 `tools/bitwarden/`，其账号缓存与 DoneBot 自身凭据隔离。

API 密钥和主密码存入本工作区现有加密密码库，不回传界面。会话解锁密钥仅驻留进程内存。列表只包含名称、站点、用户名和可用字段，密码及密钥在使用时读取；登录由原有浏览器填充流程处理，密钥由原有 `request_credential` 引用流程交给工具。Bot 不得打印密钥值。

可使用的引用为 `bw://<项目 ID 或名称>[/<字段>]`。字段支持 `password`、`username`、`totp`、`notes` 和自定义字段。名称重复时必须指定项目 ID。修改、删除项目请在 Bitwarden 中操作；DoneBot 中的来源条目只读。

刷新重新同步名称和字段。断开会清除保存凭据、内存元数据及 CLI 账号缓存；进行中的读取和连接作废。MCP 引用绑定本次连接，正常重启后保留，重新连接账号后旧引用失效。连接取消会在迟到请求结束后再次断开，避免乱序请求重新保存账号。

密码库凭据和 CLI 缓存不随工作区备份、迁移或共享导出。团队 Cloud 目前不提供 Bitwarden；团队连接、成员受众和撤权隔离另行接入，不得以个人密码库替代。

隔离验证方法见 [验证记录](verification/bitwarden.md)。
