# DoneBot 统一网关接入

当前授权范围是前端及统一网关接入。保留现有 Harness、ProviderRegistry、聊天运行循环、
Bot/线程、Assignment、记忆、权限、电脑、连接器和自动化的实现。

## 界面方案

视觉主张：沿用归档 DoneBot-b2 的浅灰品牌栏、白色表单与红色主按钮，使用用户提供的
应用图标及黑色标记。内容依次是品牌、当前操作、输入项、状态反馈与相关操作。
交互主张：登录、注册、邮件验证码、重设密码和二次验证共享入口，保留键盘焦点、密码
显示切换、发送倒计时、服务端开关、安全验证与明确的错误恢复。

归档项目的文字和历史授权只作参考，不构成当前部署、发布或修改底层机制的授权。

## 网关边界

固定来源为 https://donebot.cn。账号走 `/api/v1/auth/*`；安装凭据由
`/api/v1/donebot/installations/claim` 领取，绑定网关 `donebot.group_id` 指定的活跃
聚合分组。分组名称不用于鉴权，不在客户端复制上游配置。目录、价格和余额分别从
`/api/v1/donebot/models` 和 `/api/v1/donebot/account` 读取。

LLM 根据目录的原生接口选择 Messages、Responses、Gemini 或 Chat Completions；
jev 使用 `/v1/systemone`。现有聊天驱动只增加可选传输与本地工具扩展点，其原有配置
和运行规则保留。媒体使用固定协议适配器、独立 SQLite 任务及原会话附件；不替换
原版调度器或新建 Agent 循环。

账号密码不持久保存。登录 token 与安装凭据只交给服务端内存和 Electron 主进程的
系统加密存储，renderer 仅接收非秘密账号状态；无安全加密时仅保留本次会话。
退出登录取消活动传输，媒体和素材记录按账号、安装身份隔离。

修改前快照：`/Users/zluo/Dev/donebot-before-gateway-wb0qix97/source.tar.gz`。
网关已有相应契约，不需要为客户端改动网关业务代码。

## 原版代码核对

相对本阶段修改前快照，73 个已有文件发生变化，没有删除基线文件。完整列表见
[`donebot-gateway-audit.json`](donebot-gateway-audit.json)。其中包含图标产物和多语言目录。
`server/harness/`、`server/store.ts`、原版记忆、Assignment 和调度实现没有修改。
现有文件的服务端改动用于注册网关驱动、注入传输、路由媒体工具、账号状态及凭据限制。
原版供应商实现仍保留；运行 DoneBot 时使用已登录账号的网关服务。

登录、退出及重新登录不会重写 Bot 或线程的模型选择。线程是否跟随 Bot 默认模型，
继续由原版 `followsBotModel` 语义决定；同一个 Bot 的自动记忆召回也保留原行为。
图片、视频和音乐任务完成后通过原会话附件投递，不增加调度器自动调用 LLM 的步骤。
