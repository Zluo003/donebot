# 默认媒体模型与 Muse 视频

在设置的 DoneBot 账号／AI 模型页面，打开“默认媒体模型”，分别选择图片、视频的
首选模型和备用模型，点击“保存媒体设置”。备用可以留空；首选选择“自动选择已启用
模型”时，使用当前账号目录中客户端已支持的默认模型或首个可用模型。

列表来自网关当前账号实际开放的模型，并与客户端登记过的适配器取交集。未启用、
接口不匹配或客户端尚未支持的模型不会成为新选项。已保存但被停用的值保留显示；
有可用备用时使用备用，否则报告不可用，不任意更换用户指定的模型。

偏好按账号保存在当前工作区，重启后保留。电脑与 Cloud 的工作区分别保存自己的
偏好，本次没有增加跨工作区同步。音乐仍使用 Suno v6，TTS 保持现有接口。

## 调用顺序

本次明确指定的渠道优先；否则，先遵循该 Bot 已记忆的对应媒体渠道，再使用设置的
首选模型、备用模型。例如“以后优先用即梦 CLI 生成图片”，通过原版 profile／memory
工具保存，后续依次使用即梦 CLI、图片首选、图片备用。一次性指定不改长期偏好。

第三方 CLI、MCP、技能继续使用自身能力和原版安装、授权与执行机制；第三方媒体
能力不会被内置模型的限制覆盖，DoneBot 网关凭据也不会传给第三方。LLM 仍仅经过
统一网关。第三方明确失败或确定不可用后，Bot 应说明原因并进入设置的网关链；
第三方任务待处理、超时或结果不明时，不能再提交另一项可能重复收费的生成。

## 失败说明与备用确认

客户端在首选提交前校验两套原生参数和参考文件，保存同一项工作的首选、备用计划。
首次 LLM 工具 schema 已包含两套模型 ID、字段及限制，无需先做模型发现或能力查询。
不同模型使用各自请求格式，例如 Muse 的 `prompt/reference_images` 与 Seedance 的
`content` 不混用。参数同时绑定首选和备用 ID，设置在工具调用前变更时拒绝旧 schema。

首选任务明确返回 `failed`、原收据确认失败／退款，或创建请求明确以 400／422 拒绝
后，Bot 先在原会话说明失败原因和将使用的备用模型。图片无需再次确认，告知后继续；
视频显示确认卡，用户允许后才提交，拒绝则结束。已有 Full Access／免确认授权时
不再重复确认视频，但仍先告知。确认等待持久保存，重启后可继续处理同一张卡。

最多转入备用一次，备用失败后不递归重试。首选任务和备用任务使用不同且持久化的
幂等键，原任务 ID、收据与错误保留在工作记录中，产物仍回传原会话，并标明实际模型。

`uncertain`、网络超时、429、5xx、结算中、下载未就绪均继续原任务。停止等待、移除
原会话或账号不匹配时不派发备用；重启也不重新创建已受理的请求。参考文件在等待
期间改变时拒绝派发。备用不能接受同一批参考素材或所需操作时，工具必须传入
`fallback_parameters: null` 并说明原因，不能丢素材或降低要求来凑备用请求。

## Muse 契约与部署

依据网关项目 `docs/muse-api.md` 登记公开 ID `muse-video`：文生视频、最多 10 张
参考图、720p、16:9／9:16、4–10 整数秒，默认 6 秒。不支持音视频参考、编辑、续写
或流式输出。参考图使用会话允许文件的 `local_path`，由现有网关素材机制上传。

使用 POST `/v1/videos` 创建，查询同一个任务，最终通过 content 下载。安装任务在
`processing` 且 `generation_status=completed` 时释放生成名额并继续等待交付／结算；
content 的 409 继续下载原任务，不触发备用。Muse 按实际成片时长计费，客户端不
自行计算退款或补扣，账务以网关回执为准。

网关需先部署 Muse 接口及迁移 `267_muse_video_surcharge.sql`，配置上游 Muse 能力、
公开模型映射、当前分组授权和 720p 秒价，并启用该模型。仅更新客户端不会自动开放
生产 Muse。桌面需更新应用；Cloud Bot 需更新运行服务镜像，无需为模型设置更新手机
中继服务。历史已受理任务保留查询和下载。

Seedance 新请求也遵循该网关文档，显式提交正整数时长，默认 6 秒；2.0 最大 15 秒，
2.5 最大 30 秒。自动时长 -1 不再提交；原生要求 -1 的 Seedance 2.5 edit 当前不在
网关生成工具中开放，不能伪装为普通生成。明确的延长仍使用最终总时长。

隔离验证与限制见[验证记录](verification/donebot-media-settings.md)。
