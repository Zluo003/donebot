## 成员共享文件接口

复用固定上游的 `server/host/team-files.ts`、`server/routes/team-files.ts`、`shared/team-files.ts` 及原测试。按 DoneBot 签名运行环境派生成员和角色，套餐显式提供总配额与单文件上限；不创建原版团队服务，不恢复其默认售卖额度。

新增并发路径锁和字节预留、最终额度检查、上传后再次授权、目标替换冲突和中断清理。未知归属、不可读取目录及子目录中他人的空目录均按拒绝管理处理；模板目录的大小写别名也不允许成员写入。分块超限保留 HTTP 连接以返回原因，脚本仅下载，原字节不执行。恢复和部署边界见 [验证配方](../../verification/team-files.md)。

这是文件 HTTP 基础，尚不包含正式界面、Bot 挂载和授权写入、模板库发布、公告、个人连接与分层记忆、手机团队展示。实际 Cloud worker、真实 Linux 沙箱、备份恢复及平台仍未验收，不能视为本批完成或发布准备完成。
