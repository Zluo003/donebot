# DoneBot 原版服务入口屏蔽

`src/donebot/services.ts` 集中关闭原版促销、云服务购买与升级、Boat、移动应用下载和
邮件订阅入口。已用过应用、保存过 Boat/ModelGo 密钥的用户也适用，不依赖清空用户
数据或手动关闭提示。帮助、反馈与项目链接指向 DoneBot 仓库。

更改范围为前端展示及前端对原版服务桥接的调用。原版 Electron 和服务端的
账户、远程工作区、计算机及后台机制没有删除或重写；这不等于系统级禁用全部原版
网络请求。保留本地工作区、自有服务器连接和 DoneBot 网关。未来自有服务需独立
接入，不能直接打开这些开关来恢复原版服务。

## 验证

`src/donebot/services.dom.test.ts` 在隔离 DOM 中挂载真实组件，验证已保存原版密钥时
促销卡和密钥入口仍隐藏，账户、购买、邮件订阅和移动下载组件不调用原版服务桥接，
自有服务器连接表单及本地工作区入口仍可用，旧的原版服务动作不再执行。
`src/components/AppNotices.test.ts` 覆盖已使用过应用的用户，确认无原版促销弹窗及账户、套餐和价格
查询。保留功能的原有用例在测试夹具中显式开启开关继续回归。

本轮前端相关测试与 DoneBot 网关客户端专项合计 57 个文件、946 项通过。媒体端到端
用例由 `launchVerificationServer` 创建独立 HOME、数据目录和端口，只访问合成网关。
这些结果不等于对用户安装版本、全部原生菜单或线上上游做了实测。
